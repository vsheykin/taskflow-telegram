# 📋 Система повторных напоминаний

## 🎯 Что реализовано

### 1. Точное время напоминаний
- При создании задачи с напоминанием устанавливается **таймер** в браузере
- Напоминание приходит **точно в указанное время** (если приложение открыто)
- Если приложение закрыто - напоминание отправляется при следующем открытии

### 2. Повторные напоминания
Если пользователь не отреагировал на задачу, отправляются повторные уведомления:

| № | Когда | Текст |
|---|-------|-------|
| 1 | В указанное время | 🔔 Напоминание о задаче |
| 2 | +30 минут | ⏰ Повторное напоминание (+30 мин) |
| 3 | +1 час | ⏰ Повторное напоминание (+1 час) |
| 4 | +8 часов | ⏰ Финальное напоминание (+8 часов) |

После 4-го напоминания задача помечается как `reminder_sent: true` и больше не беспокоит.

### 3. Исправлены спецсимволы
- URL-encoded символы (`%0A`) заменены на настоящие переносы строк
- HTML-спецсимволы (`<`, `>`, `&`) экранируются для безопасности

## 🗄️ Настройка базы данных

### Выполните SQL-скрипт

Откройте Supabase → SQL Editor и выполните код из файла `supabase/add-reminder-fields.sql`:

```sql
-- Добавляем поле для подсчёта отправленных напоминаний
ALTER TABLE tasks ADD COLUMN IF NOT EXISTS reminder_count INTEGER DEFAULT 0;

-- Добавляем поле для времени последней отправки напоминания
ALTER TABLE tasks ADD COLUMN IF NOT EXISTS last_reminder_sent_at TIMESTAMP WITH TIME ZONE;

-- Обновляем существующие задачи
UPDATE tasks SET reminder_count = 0 WHERE reminder_count IS NULL;
```

## 📱 Как это работает

### При создании задачи:

1. Пользователь выбирает время напоминания
2. Приложение сохраняет задачу в Supabase
3. Если время напоминания < 24 часа - устанавливается **таймер** в браузере
4. Если время > 24 часа - будет проверено при следующем открытии

### При срабатывании таймера:

1. Отправляется уведомление в Telegram
2. Показывается локальное уведомление (если разрешено)
3. Обновляется `reminder_count` и `last_reminder_sent_at` в БД

### При открытии приложения:

1. Проверяются все задачи с `reminder_sent: false`
2. Для каждой задачи проверяется:
   - Прошло ли время напоминания?
   - Сколько напоминаний уже отправлено?
   - Прошло ли достаточно времени с последнего напоминания?
3. Если нужно - отправляется напоминание

### Повторные напоминания:

```
Задача создана с напоминанием на 14:00

14:00 → 🔔 Первое напоминание (reminder_count: 1)
14:30 → ⏰ Повторное (+30 мин) (reminder_count: 2)
15:00 → ⏰ Повторное (+1 час) (reminder_count: 3)
22:00 → ⏰ Финальное (+8 часов) (reminder_count: 4)

После 4-го напоминания: reminder_sent = true
```

## 🔧 Настройка GitHub Actions

Workflow `.github/workflows/reminders.yml` обновлён для поддержки повторных напоминаний:

- Использует `jq` для правильного формирования JSON (без `%0A`)
- Обновляет `reminder_count` и `last_reminder_sent_at`
- Запускается каждые 6 часов для подстраховки

## 🧪 Тестирование

### Тест 1: Точное время

1. Создайте задачу с напоминанием через 2 минуты
2. Подождите 2 минуты
3. Должно прийти уведомление **точно в указанное время**

### Тест 2: Повторные напоминания

1. Создайте задачу с напоминанием на сейчас
2. Не отмечайте задачу как выполненную
3. Через 30 минут должно прийти повторное напоминание
4. Через 1 час - ещё одно
5. Через 8 часов - финальное

### Тест 3: Спецсимволы

1. Создайте задачу с названием `Тест <script>alert(1)</script>`
2. Установите напоминание
3. В уведомлении должно быть: `Тест &lt;script&gt;alert(1)&lt;/script&gt;`

## 📊 Проверка в базе данных

```sql
-- Посмотреть все задачи с напоминаниями
SELECT 
  id,
  title,
  reminder_date,
  reminder_count,
  last_reminder_sent_at,
  reminder_sent
FROM tasks
WHERE reminder_date IS NOT NULL
ORDER BY reminder_date DESC;

-- Сбросить напоминания для тестирования
UPDATE tasks
SET 
  reminder_count = 0,
  reminder_sent = false,
  last_reminder_sent_at = NULL
WHERE id = 'YOUR_TASK_ID';
```

## ⚠️ Ограничения

### Таймеры в браузере

- Таймеры работают **только когда приложение открыто**
- Если вкладка закрыта - таймеры не сработают
- Максимальное время таймера: 24 часа (ограничение браузера)
- Для напоминаний > 24 часов используется проверка при открытии

### Повторные напоминания

- Работают только если приложение периодически открывается
- Если приложение не открывается 8+ часов - повторные напоминания не отправятся
- GitHub Actions запускается каждые 6 часов для подстраховки

### Локальные уведомления

- Требуют разрешения пользователя
- Работают только в поддерживаемых браузерах
- Не работают в Telegram Web App (только Telegram уведомления)

## 🆘 Решение проблем

### Проблема: Напоминание не приходит в точное время

**Причина:** Вкладка браузера закрыта или таймер > 24 часов

**Решение:**
- Держите вкладку открытой
- Или используйте GitHub Actions для проверки

### Проблема: Повторные напоминания не отправляются

**Причина:** Приложение не открывается

**Решение:**
- Открывайте приложение хотя бы раз в 8 часов
- GitHub Actions проверяет каждые 6 часов

### Проблема: Спецсимволы в уведомлениях

**Причина:** Старая версия кода

**Решение:**
- Запушьте последние изменения
- Дождитесь деплоя
